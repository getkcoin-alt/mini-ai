A universal human context framework for AI companions · Age 8–100+

Imagine an AI that doesn't simply remember your name, age, profession, or previous conversations.

It understands:

- What made you who you are.
- What makes you happy, angry, afraid, or motivated.
- What you are trying to achieve.
- What you believe in.
- What you struggle to communicate.
- What you need today.
- What you might need tomorrow.
- How to support you without controlling you.

The objective is to create a Universal Human Context Database (UHCD) — a structured knowledge system that allows any authorized AI to understand an individual and become a helpful, trustworthy partner.

Recommendation: build it as a lifelong, evolving profile, not a static form that a person fills out once.

There is one important principle:

**The AI should know enough to understand the human, but should never assume it owns the human's information. Personal data must be consensual, protected, editable, and deletable. This is especially important for children aged 8–17.**

## 4. The information that makes AI genuinely intelligent about a human

The 30 groups describe what the AI could know. There is another dimension: understanding the relationships between those facts.

Example:
- The person wants to become financially independent.
- They are currently working long hours.
- They value family time.
- They dislike unnecessary risk.
- They have limited free time.

A basic AI sees five independent facts. A good AI recognizes a potential conflict between financial ambition, time availability, and family priorities. This requires five additional intelligence layers.

### Five intelligence layers
1. **Descriptive intelligence** — What is true about the individual? Facts, preferences, identity, skills, history.
2. **Contextual intelligence** — Why does this information matter? Circumstances, relationships, environment, constraints.
3. **Temporal intelligence** — How has this person changed? Past experiences, current state, evolving goals, life transitions.
4. **Predictive intelligence** — What might happen next? Possible outcomes, risks, opportunities, needs. Predictions must remain uncertain, not become facts.
5. **Partnership intelligence** — How can AI help without taking control? Recommendations, reminders, collaboration, accountability, independent human choice.

## 5. The universal database should capture more than answers

Every meaningful piece of human information should have additional metadata. Instead of saving `Favourite food = Pizza`, save:

| Attribute | Value |
|---|---|
| Category | Food preference |
| Value | Pizza |
| Status | Active |
| Source | User explicitly stated |
| Confidence | High |
| Last confirmed | 2026-11-10 |
| Sensitivity | Low |
| Permission | Personal AI only |
| Expiry | Review in 12 months |

Universal metadata fields: person_id, attribute_id, category, attribute_name, value, data_type, source, confidence, verification_status, sensitivity_level, consent_status, permitted_ai_agents, created_at, updated_at, last_confirmed_at, valid_from, valid_until, expiration_policy, visibility, deletion_status.

**Critical distinction: AI observations, AI-generated hypotheses, and user-confirmed facts must never be stored as if they are the same thing.**

## 6. Information should be divided into access levels

| Level | Data access | Example |
|---|---|---|
| L0 | Public | Public professional profile |
| L1 | Personal preferences | Language, interests, response style |
| L2 | Private context | Goals, relationships, personal history |
| L3 | Sensitive | Health, finances, intimate experiences |
| L4 | Highly restricted | Identity documents, precise location, protected records |

Access should be granted separately for each agent, purpose, and period. L4 information should generally remain outside the general-purpose memory system.

For children, apply additional age-appropriate safeguards, guardian involvement where legally required, and strong restrictions on profiling and sharing. Never create a permanent psychological dossier on a child.

## 7. How to build this database

Not one enormous table with 500 columns: a modular, graph-based human knowledge system — the Universal Human Context Engine.

- Human Identity: one permanent profile ID, controlled by its owner.
- Structured Memory · Relationship Graph · Timeline Memory · Semantic Memory · Consent & Permissions · Behavioural Context.
- Human Context API: authentication · permission checking · context retrieval · updates.
- Consumers: AI Assistant, AI Tutor, AI Partner, AI Doctor (requires clinical authorization and safeguards), AI Career Agent, AI Business Agent.

Recommended technical architecture:

| Component | Technology | Purpose |
|---|---|---|
| Main database | PostgreSQL | Structured human attributes |
| Graph relationships | PostgreSQL graph model initially | People, events, relationships |
| Vector memory | pgvector | Semantic memory retrieval |
| Cache | Redis | Fast context access |
| API | FastAPI | Universal human context API |
| Event system | Redis Streams | Memory updates and synchronization |
| File storage | Encrypted object storage | Documents and user-owned records |
| Authentication | OAuth2 / OIDC | Identity and access control |
| Encryption | KMS + field-level encryption | Sensitive information protection |

## 9. The Human Synchronization Protocol

A person moving between AIs should not have to explain their life again.

1. Human creates identity profile → 2. Build personal knowledge graph → 3. Collect information with consent → 4. Validate and classify memories → 5. Store facts, events and relationships → 6. Human Context API → 7. New AI requests access → 8. Verify identity and permissions → 9. Generate relevant context package → 10. AI understands the human → 11. AI provides contextual assistance → 12. Human approves memory updates → back to 5.

The synchronization package contains: basic identity context, communication preferences, relevant personal history, current goals, current responsibilities, relevant relationships, active projects, relevant memories, known constraints, explicitly authorized sensitive context, source and confidence metadata. It should not dump the entire database into every AI conversation; context is retrieved according to task and permission level.

## 10. Things the AI should NEVER automatically assume

| AI must not assume | Correct behaviour |
|---|---|
| A person has not changed | Reconfirm outdated information |
| An observation is a fact | Mark it as an inference |
| A person wants advice | Ask whether advice is wanted |
| Family members have access | Require individual consent |
| Past goals remain relevant | Check current priorities |
| Silence means agreement | Request confirmation |
| A person's weakness is an opportunity | Protect against manipulation |
| More data means better AI | Collect only useful information |
| Age determines ability | Assess the individual |
| AI knows what is best | Preserve human autonomy |

## 11. Final recommendation: make it a universal standard — HUMAN OS

Universal Human Context Infrastructure.

- **Mission:** Every human should have the ability to own a continuously evolving digital representation of their preferences, experiences, knowledge, goals, and personal context.
- **Vision:** Any authorized AI can understand the individual without forcing them to start their life story from zero.
- **Core principle:** Your life. Your information. Your permissions. Your AI.
- **Stages:** Human OS Foundation (taxonomy, data types, relationships, metadata, privacy model) → Human OS Memory (API, database, memory engine, user-controlled sync) → Human OS Ecosystem (other AI providers and specialized agents use the same authorized context).

Don't just build a database of who someone is. Build a database of **who someone was, who they are now, and who they want to become.**

The catalogue is a proposed starting taxonomy, not a claim that all 30 groups apply to every human. The next engineering step is a versioned, internationally usable JSON Schema and PostgreSQL implementation.

The ultimate objective isn't to make AI know everything about humans. It's to make humans never have to feel misunderstood by their technology again.
