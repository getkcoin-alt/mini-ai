# Mini AI ✦

**A little more human. A lot more you.**

An animated, mobile-first design prototype for a voice-first AI companion that can feel like a best friend and an effective mentor.

**Live capability boundary:** This repository currently contains an **interactive frontend demo only**. Google OAuth, email verification, Scriwo WhatsApp OTP, real AI reasoning, true long-term memory, cloud sync, and hardware pairing **are not connected**. Browser speech recognition / speech synthesis are best-effort platform APIs; scripted answers are not generated by an LLM.

## Try it locally

No dependencies, build system, API key or database are needed. Serve the repo root with any static web server (HTTPS or localhost recommended for microphone permissions):

\`\`\`sh
python3 -m http.server 4173
# open http://localhost:4173
\`\`\`

Or deploy the Git repository directly to Vercel as a static project.

## Explore the UI

1. On the landing page, choose **Meet your Mini**.
2. Choose Google, email or WhatsApp to see the authentication UI; for OTP preview use the clearly labeled demo code **123456**, which sends **no** message and verifies **no** identity. Or select **Continue in demo mode**.
3. Answer six natural-language questions, use the microphone on supported browsers, or select **I'll tell you later**.
4. Try Friend/Mentor modes, talk into the mic or reveal the optional keyboard, and watch profile sync update.
5. Adjust preferences under **Our dynamic** and clear local preview data under **Preferences**.

## Accessibility & privacy in the prototype

- Mobile bottom navigation, legible focus outlines, captions and reduced-motion styles.
- Profile preferences are saved in **browser localStorage**, not to any server. Do not enter sensitive data into this demo.
- No silent microphone access, voiceprint collection or real memory write.
- Honest disclosure of mock responses and mock verification throughout.

**Our direction:** earn trust through one excellent real-time conversation before expanding into multimodal agents, cross-device continuity and physical Mini hardware.
